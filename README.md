# Temperature Controlled Fan

## Overview

This hobby project demonstrates a temperature-controlled fan system implemented using 8051 Assembly Language in Keil µVision 5.

The system simulates temperature variations and automatically controls fan operation based on predefined temperature thresholds.

## Features

* Simulated temperature sensing
* Automatic fan control
* Temperature display using Port 1
* Fan status control using Port 2
* 8051 Assembly Language implementation

## Working Principle

* Temperature < 25°C → Fan OFF
* Temperature 25°C–30°C → Fan LOW
* Temperature 30°C–35°C → Fan MEDIUM
* Temperature > 35°C → Fan HIGH

## Tools Used

* Keil µVision 5
* 8051 Microcontroller
* Assembly Language
